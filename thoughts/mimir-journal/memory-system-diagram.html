The API

Plug it in

The whole API is two calls. Wrap them around your model and you're done.

recall(query, scope) → context
Before the answer
Wide candidates → rerank → top-10 raw turns, best-first, plus PROFILE + SPINE, budget-capped. Carries an abstain signal so you know when it doesn't know.
remember(turn, scope) → ack
After the answer
Fire-and-forget: the extractor makes atomic facts, the bitemporal reconciler versions them (ADD / UPDATE / DELETE / NOOP), the index updates. Next recall sees it.

One scope, or many

Same engine. Separate by scope tag, never a per-domain schema. Adding a domain is one new tag string.
